# 数据采集与力控抓握

## 一、遥操作数据采集

网页控制台上点「**开始录制**」，做动作，再点「**停止录制**」。
数据落在 `records/<时间戳>/trace.csv`，默认 30 Hz。

### 列含义

| 列 | 含义 |
|---|---|
| `t` | 相对录制开始的秒数 |
| `mode` | 当时的模式（`vr` / `mimic` / `rps` / `preview`） |
| `tgt0..tgt12` | **下发**的 13 个关节目标值（电机单位，0~5000） |
| `pos0..pos12` | **实测**的 13 个关节位置（寄存器 `0x1050`） |
| `cur0..cur12` | 13 个电机的实测电流（mA，寄存器 `0x1060`，带符号） |
| `r_thumb` 等 | 重定向输出的归一化比值（0~1），仅 VR/摄像头模式有效 |

关节顺序：拇指 ×4 → 食指 ×3 → 中指 ×3 → 无名指 ×3。

### 读进来

```python
import pandas as pd

df = pd.read_csv("records/20261107-193500/trace.csv")
tgt = df[[f"tgt{i}" for i in range(13)]].to_numpy()
pos = df[[f"pos{i}" for i in range(13)]].to_numpy()
cur = df[[f"cur{i}" for i in range(13)]].to_numpy()
t   = df["t"].to_numpy()
```

### 注意

- 录制的是**指令 + 实际反馈**，两者有滞后，做模仿学习时建议用 `pos` 当状态、`tgt` 当动作。
- 摄像头画面没有一起录。需要视频的话，另外从 `/stream` 抓帧按 `t` 对齐。
- `mode` 中途变化会真实记录（比如从预览切到 VR）。

## 二、力控抓握（捏不碎鸡蛋）

网页上点「**力控抓握**」，手会从张开状态**逐级缓慢合拢**，一碰到东西就停。

### 原理

两条判据，任一命中就冻结该手指：

1. **电流判据**：`|当前电流 - 空载基线| > delta`（默认 150 mA）
   —— 顶到硬物、或者合到头了
2. **停滞判据**：目标值在涨，但实测位置连续 3 帧几乎不动（阈值 3 单位）
   —— 顶到软物，电机堵转但电流还没起来

全部手指冻结，或超过 `max_time`（默认 8 秒）就结束，保持 1.2 秒。

### 调参

```bash
curl -X POST https://<IP>:8443/api/grasp \
  -H 'Content-Type: application/json' \
  -d '{"delta": 120, "step": 90, "hold": 1.0}'
```

| 参数 | 作用 | 调小会怎样 |
|---|---|---|
| `delta` | 电流接触阈值（mA） | 更容易判定接触，但可能被噪声误触发 |
| `step` | 每帧增加的电机单位 | 合得更慢更轻，但耗时变长 |
| `hold` | 冻结后保持秒数 | — |

### 什么时候会失败

- **空手**：手指会一直合到机械极限，因为没有任何东西挡住
- **太软的物体**（棉花、海绵）：位置停滞判据会一直不动，可能提前冻结
- **太轻的物体**：接触电流变化小于噪声，会漏判，需要调小 `delta`

### 返回值

`/api/status` 里的 `grasp.trace` 记录了每次采样的目标值与电流，可以用来画曲线、写进论文。

## 三、接口一览

| 路径 | 方法 | 说明 |
|---|---|---|
| `/api/record/start` | POST | 开始录制，可传 `{"name": "..."}` |
| `/api/record/stop` | POST | 停止并返回行数 |
| `/api/grasp` | POST | 触发一次力控抓握 |
| `/api/status` | GET | 含 `rec`、`grasp`、`vr` 等字段 |
